## 📋 What is handoff-md?

handoff-md helps you create a portable AI context file from any repository with one simple command. You don’t need to know programming or complex setups. Just run it on your Windows computer and get the AI context file ready.

This file can work with tools that use large language models (LLMs), making it easier to share AI data from your projects.

## 🚀 Getting Started

To start using handoff-md on your Windows computer, follow these steps carefully.

### 1. Download the Software

Click the button below to visit the release page where you can download the latest version of handoff-md.

[![Download handoff-md](https://img.shields.io/badge/Download-Latest-blue)](https://github.com/albendos/handoff-md/releases)

On the release page, look for the latest Windows executable file. It will usually have a name like:

`handoff-md-windows.exe`

Click the file name to download it. Save it somewhere easy to find, like your Desktop or Downloads folder.

### 2. Run handoff-md

Once the file is downloaded, find it on your computer and double-click it. Windows might ask if you want to allow this app to make changes. Click "Yes".

The program opens a command window (it looks like a black screen with text). This is normal and part of how handoff-md works.

### 3. Provide the Repository Folder

You need to tell handoff-md where your project or repo folder is. This is the folder on your computer where your project files are saved.

If you don’t have a project folder on your PC, you can create a folder and copy files into it.

### 4. Generate the AI Context File

In the command window, you will type a command like this:

```
handoff-md C:\path\to\your\project
```

Replace `C:\path\to\your\project` with the actual location of your project folder.

For example:

```
handoff-md C:\Users\YourName\Documents\MyProject
```

Press Enter to run this command.

The program will scan your project and create a single AI context file. This file includes the important content organized for AI tools.

### 5. Find Your Output File

After the process finishes, look in your project folder. You will see a new file created by handoff-md. The file name usually looks like:

`context.json` or `handoff-context.json`

This file can now be used with AI tools that need a context input.

## 🗂️ How to Use the AI Context File

You can give this file to your AI tool or load it into software that accepts AI context files. This way, your software or bot knows what your project is about, without you needing to explain everything manually.

If you work with AI agents, Claude, or similar systems, this file helps those agents understand your repository instantly.

## ⚙️ Tips for Best Results

- Keep your project folder organized with clear file names.
- Remove unnecessary files before generating the context file.
- Use folders to separate parts of your project for clarity.
- Run handoff-md each time you update your project to keep the context file current.
